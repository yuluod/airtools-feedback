# 更新日志

本项目所有重要变更都将记录在此文件中。

## [v0.1.27] - 2026-03-17

正式版授权与反馈体验修复：激活更稳定，错误提示更准确

### 修复
- 修复：正式版中部分用户激活时可能提示“网络错误”的问题
- 修复：授权校验、解绑和反馈提交在正式版中的连接异常问题

### 改进
- 优化：激活失败时的错误记录更清晰，便于后续排查问题

## [v0.1.26] - 2026-03-17

设置与授权体验继续重构，首页与导航交互更完整，工程测试与发布基线同步增强

### 新功能
- 新增：设置页结构重做，导航、搜索、锁定提示与返回逻辑更统一
- 新增：授权支持邮箱激活、设备标识查看与复制，以及更多状态提示
- 新增：侧边栏分类筛选、反馈附加字段与更完整的 Docker run 解析/校验能力

### 改进
- 优化：设置页布局、授权标记和升级入口统一，Free / Trial / Pro 状态展示更清晰
- 优化：首页、标题栏、侧边栏与工具卡片的交互和视觉层级，返回、搜索、分类与滚动体验更顺手
- 优化：工具排序与历史/数据/模块锁定态的引导文案和只读预览，减少进入后才发现不可用的情况

### 修复
- 修复：主题根 class 同步与暗色表面样式问题，减少深浅色切换时的背景错位与发灰感
- 修复：Toast/弹窗初始显示、设置导航裁切、RSA 密钥生成失败状态保留、高亮与输入识别等细节问题
- 修复：激活流程中的新增错误码适配与部分国际化文案缺失问题

## [v0.1.25] - 2026-02-22

启动与工具体验优化：冷启动更顺滑，文本处理与可访问性交互更一致

### 新功能
- 新增：Diff、Regex、文本去重工具统一接入行内差异高亮，并提升大文本高亮上限（最高 10000 行）
- 新增：更新检查中的更新日志支持 Markdown 渲染，信息展示更完整

### 改进
- 优化：应用冷启动速度与启动过程流畅性，进入主界面更顺滑
- 优化：启动页图标与标题显示稳定性，减少启动瞬间的轻微跳动
- 优化：多种双向转换工具切换方向时默认清空输入，减少结果混淆
- 优化：关键页面的键盘操作与无障碍体验，导航与反馈更一致

### 修复
- 修复：时间戳工具在部分输入场景下可能报错的问题
- 修复：部分工具首次打开时可能出现状态未正确加载的问题
- 修复：Regex 与图片 Base64 工具在匹配与拖拽操作中的细节问题

### 维护
- 维护：提升 Windows 下发布流程稳定性（不影响日常使用）

## [v0.1.23] - 2026-02-10

更新体验更清晰，图片压缩更稳定，并带来安全性增强
